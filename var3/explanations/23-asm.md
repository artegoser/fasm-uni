# Задание 23. AVX, FASM

В примере 2 раздела AVX методички `VMOVUPS` загружает два вектора по восемь float, `VMULPS` перемножает их, а `VMOVUPS` сохраняет произведения. Здесь это же умножение выполняется в `use16` DOS COM. Переход в 16-битный защищённый режим нужен для запуска AVX из DOS. C++-пример методички выполняется в режиме, который уже настроила операционная система. Об ограничении режима подробнее написано в [описании сборки](../README.md).

Исходник — [23.asm](../23.asm). Номера соответствуют строкам файла. Пустые строки и строки, которые уже состоят из комментариев, пропущены.
