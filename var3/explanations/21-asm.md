# Задание 21. MMX, FASM

Вариант 3 из методички требует старшие 16 бит знаковых произведений. Как в примере с `PMULHW`, одна команда обрабатывает четыре пары слов. В этом файле есть также скалярный вариант и замер обоих вариантов без вывода.

Исходник — [21.asm](../21.asm). Номера соответствуют строкам файла. Пустые строки и строки, которые уже состоят из комментариев, пропущены.
