# Задание 22. SSE, C++

Пример 2 из методички использует `MOVUPS` и `MULPS` для четырёх пар float. По заданию нужны два варианта умножения и замер без вывода. Здесь скалярный вариант использует x87, а векторный домножает остаток массива по одному элементу.

Исходник — [cpp/22.cpp](../cpp/22.cpp). Номера соответствуют строкам файла. Пустые строки и строки, которые уже состоят из комментариев, пропущены.
