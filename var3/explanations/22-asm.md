# Задание 22. SSE, FASM

Вариант 3 требует поэлементно умножить два массива float. Пример из методички использует `MOVUPS` и `MULPS` для четырёх пар. В этом файле скалярный вариант умножает на x87, и оба варианта замеряются без вывода.

Исходник — [22.asm](../22.asm). Номера соответствуют строкам файла. Пустые строки и строки, которые уже состоят из комментариев, пропущены.
